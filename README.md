# BatteryTune

Утилита для Windows-ноутбуков, которая сама определяет железо и батарею, показывает отчёт и переключает режимы энергопотребления. Один батник — и можно растянуть автономность.

## Возможности

- **Автоопределение железа**: CPU, встроенная и дискретная видеокарта, батарея, экран.
- **Отчёт о батарее**: проектная и реальная ёмкость, здоровье, износ, циклы, текущий расход и прогноз времени работы.
- **Режим «Эконом»**: лимит частоты CPU на батарее + отключение дискретной видеокарты.
- **Режим «Максимум»**: снятие лимитов + включение дискретки.
- **Переключение яркости** 50% / 100%.
- Не трогает настройки от сети: воткнул зарядку — мощность вернулась сама.
- Поддерживает NVIDIA, AMD и Intel; ноутбуки без дискретки тоже работают.

## Требования

- Windows 10 или 11
- PowerShell 5.1 (встроенный)
- Права администратора — только для включения/выключения дискретной видеокарты

## Запуск

1. Скачай или склонируй репозиторий.
2. Двойной клик по **`BatteryTune.bat`**.
3. В окне UAC нажми **«Да»**.

Откроется меню:

```
[1] Эконом   — CPU 60%, Turbo off, дискретка off
[2] Максимум — CPU 100%, Turbo on, дискретка on
[3] Отчёт о системе и батарее
[4] Яркость 50% / 100% (переключить)
[0] Выход
```

### Из командной строки

```powershell
powershell -ExecutionPolicy Bypass -File BatteryTune.ps1 -Action report
powershell -ExecutionPolicy Bypass -File BatteryTune.ps1 -Action eco
powershell -ExecutionPolicy Bypass -File BatteryTune.ps1 -Action max
powershell -ExecutionPolicy Bypass -File BatteryTune.ps1 -Action status
```

Параметры:

| Параметр | Описание |
|---|---|
| `-EcoCpu 50` | Лимит CPU на батарее в эконом-режиме (по умолчанию 60) |
| `-NoGpu` | Не трогать дискретную видеокарту |
| `-Force` | Не спрашивать подтверждение при отключении GPU |

## Как это работает

**Лимит CPU.** Через `powercfg` меняются настройки активной схемы питания только для работы от батареи:

- `PROCTHROTTLEMAX` — максимальное состояние процессора (например, 60%);
- `Processor performance boost mode` — Turbo Boost выключается.

От сети эти значения не меняются, поэтому при подключении зарядки ограничения снимаются автоматически.

**Дискретная видеокарта.** Утилита находит дискретный адаптер по вендору (NVIDIA, Radeon RX/Pro, Intel Arc) и отключает его через `Disable-PnpDevice`. На Optimus-ноутбуках экран остаётся на встроенной графике, а дискретка перестаёт потреблять энергию в простое.

**Отчёт.** Ёмкость и циклы берутся из `powercfg /batteryreport`, текущий расход — из WMI `BatteryStatus`. Здоровье считается как реальная ёмкость / проектная.

## Безопасность

- Отключение дискретки обратимо: пункт «Максимум» или `-Action max` включает её обратно.
- Перед отключением проверяется, что батарея есть, адаптеров минимум два и среди них есть встроенная графика. Если GPU — единственный адаптер, утилита откажется его выключать.
- Если экран всё же погас (редкий случай на ноутбуках с MUX), перезагрузись и запусти `BatteryTune.bat` → «Максимум». Либо включи устройство вручную: Диспетчер устройств → Видеоадаптеры → нужная карта → «Включить устройство».
- Утилита не удаляет драйверы, не меняет реестр и не ставит службы.

## Ограничения

- Частоту обновления экрана не меняет — это делается вручную в параметрах дисплея.
- Яркость регулируется только на встроенном экране (внешние мониторы не поддерживают WMI-яркость).
- На некоторых ноутбуках дискретка не уходит в сон из-за драйвера; отключение — самый надёжный способ.
- Значения расхода и прогноза обновляются контроллером батареи с задержкой в несколько секунд.

## English

BatteryTune is a universal Windows laptop battery tuner. It auto-detects the CPU, iGPU/dGPU, battery health and screen, prints a detailed report, and switches between an eco mode (CPU cap on battery + discrete GPU disabled) and a max mode (no limits + GPU enabled). CPU limits apply only on battery; AC power is never touched. Admin rights are required only to toggle the discrete GPU.
